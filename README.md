# Flotsam 浮游世界 漂流品 模组合集 · FlotsamModKit

为 [Flotsam](https://store.steampowered.com/app/1176020/Flotsam/)（1.0.1f7 / Windows / Steam）制作的十件套模组合集。

底层是 **BepInEx 5.4.23 + HarmonyX** 注入，上层是自研的 **FlotsamModKit** 宿主：统一发现、启停、改键、配置、补丁与 UI 服务。所有窗口复用游戏本体的贴图与字体（原汁原味的观感），可拖拽、可缩放、自动记忆位置；所有游戏操作尽量走游戏原生逻辑，**连线、加点、排产等结果均随存档保存**，禁用模组即整体回滚，不修改任何游戏本体文件。

作者：**临渊**

## 模组一览

| 模组 | 默认按键 | 一句话 |
|---|---|---|
| 键盘航行 | `W/S/A/D`，`F8` 暂停 | 不打开世界地图，直接用键盘开船 |
| 建筑总览 | `B` | 全部建筑按原生分类检索、搜索、一键定位 |
| 材料助手 | `G` / `H` | 缺什么材料、去哪造、一键补齐整条链 |
| 常驻小地图 | `M` 开关 | 永驻小地图 + 点哪儿自动航行到哪儿 |
| 游戏性调整 | `F7` | 九个滑块自由改平衡（100% = 原版） |
| 批量管理 | `Ctrl+1` | 按型号勾选，批量拆除 / 升级 / 启停 |
| 一键电网 | `Ctrl+2` | 所有未供电建筑按最短电缆接入电网 |
| 自动任务优先级 | `Ctrl+3` / `Ctrl+4` | 小人自动排任务优先级 + 自动加技能点 |
| 自动派工 | `Ctrl+5` / `Ctrl+6` | 收集 / 打捞自动计算最优派遣人数 |
| 性能优化与探针 | `F9` | 性能面板 + 一揽子帧率优化 |

所有按键均可在游戏内 `F10` 管理器改键。每个模组的详细说明与全部配置项见 [`ModKit/使用说明.md`](ModKit/使用说明.md)。

## 安装（玩家）

1. 找到游戏安装文件夹（`Flotsam.exe` 所在文件夹）。Steam 中：库 → 右键 Flotsam → 管理 → 浏览本地文件。
2. 解压整合包 zip 里的**全部内容**到该文件夹，提示合并时选「是」。
3. 正常启动游戏。首次启动生成 BepInEx 缓存，主菜单慢 1~2 秒属正常。

安装成功的标志：

- 主菜单出现提示「Flotsam ModKit 就绪：N/N 个模组已启用（F10 打开管理器）」；
- 按 `F10` 打开模组管理器，可启停模组、改键、查日志；
- 排错日志在 `BepInEx\LogOutput.log`（每次启动覆盖）。

**卸载**：删除游戏文件夹内的 `BepInEx\`、`Mods\`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 五项即可，不影响游戏本体与存档。

### 常见问题

- **杀软报毒 / 游戏起不来**：`winhttp.dll` 是 BepInEx 的注入组件（Doorstop 代理），常见误报，加入白名单即可。
- **装过其他 BepInEx 或旧版 ModKit**：先删干净（见上「卸载」）再解压本包。
- **游戏更新到新版本**：模组可能失配，等本仓库更新。

## 各模组简介

### 键盘航行

不打开世界地图，`W/S/A/D` 直接驾驶镇心；`Enter` 立即靠港，`F8` 暂停。
屏幕上的「航行仪表」实时显示航向、速度、本段航程、累计里程与电量可航距离。
只在松手或航行一段距离后才提交一次世界坐标（与原版关地图完全同款），因此周围建筑不会被反复重建而消失；开地图自动无缝交接，地图里关掉即回到键盘航行。

### 建筑总览

`B` 或 HUD 按钮打开。左侧为游戏原生的建筑分类（原生图标 + 配色 + 数量），右侧按游戏自己的排序列出建筑（图标 / 名称 / 建造中 / 故障数），支持中英文搜索，点击一行飞向该建筑。窗口与按钮可拖拽并记忆位置，双击标题栏复位。

### 材料助手

专治「材料是悬浮展示的、鼠标一移上去就消失」：

- 建造菜单 / 工坊里的每个材料格**可以直接点**：能生产的直接飞过去并打开生产面板；不能生产的（如金属废料）告诉你能从哪些残骸打捞；
- 点一下要造的建筑 → 建造悬浮框**钉住**，不跟随鼠标；
- 常驻面板列出每种材料的 库存 / 需求 / 在途 与最近可生产建筑，每行「补齐」「定位」；
- 按住 `G` 点要造的建筑 → **整条缺料链一键补齐**（含中间材料）。

### 常驻小地图

`M` 开关的常驻小地图：真实战争迷雾、游戏本体的地标 / 兴趣点 / 漂浮物图标、自己的建筑与游泳圈，另带比例尺。滚轮以光标为中心缩放、拖拽平移、双击居中、右键回镇心；**左键单击 = 自动航行到该点**（转向、推进、刹车、靠港全自动，方向键随时接管）。键盘航行未靠港时箭头实时跟踪。

### 游戏性调整

`F7` 打开原生皮肤滑块面板，**全部以原版百分比表达（100% = 原版）**，拖动或键入均可（5% 档位），即时生效并记忆：

- **重量**：移动能耗随重量的增长（0% = 重量不再增加能耗）、牵引 / 载重上限（超重也能继续建）；
- **发电**：所有发电机（风 / 水、燃料、人力）产出效率；
- **小人**：整体执行效率（干活 + 走路一起快慢）；
- **船只**：打捞船 / 渔船航行速度（与小人效率无关的独立档）；
- **美观度**：建筑美观分的正 / 负贡献 + 美观对士气的正 / 负修正。

总开关一关即全部回原版，另有「恢复默认」。

### 批量管理

`Ctrl+1` 打开。左栏按建筑型号分组（分类可折叠，型号行带「可升 X/Y」与各状态计数），右栏列出该型号全部实例。工具条：**选可升级** / 全选 / 反选 / 清空。操作栏：批量拆除（红色内联二次确认）、取消拆除、批量升级、取消升级、启用、停用。勾选即在世界中高亮描边，`◀▶` 按勾选顺序逐个跳转核对；每座建筑先做与原生按钮相同的预检，跳过项在 Toast 汇总原因。

### 一键电网

`Ctrl+2` 一键把所有够得着的未供电建筑按**最短总电缆**接入带电网络（可经已建电线杆接力）；连接完全走游戏原生逻辑，电缆可视、故障清除、存档持久化与手动连线完全等价。可选：整理既有布线（收益 ≥10% 才动）、缺电 × 富余电网智能互济合并、自动模式（新建筑 3 秒内自动接线）。

### 自动任务优先级

- **自动优先级**（`Ctrl+3`）：按小人各任务相关技能的相对排名，最高的设「高」、中间「中」、其余「次」，让最合适的人优先接手对应工作；
- **自动加点**（`Ctrl+4`）：升级攒下的技能点自动分配——爱好优先，其次已最高的属性（专精路线），走游戏原生加点逻辑。

事件驱动、零轮询，只在升级 / 加点 / 加入 / 离开 / 死亡时触发（0.5 秒防抖合并）。关闭只停手不回滚。

### 自动派工

- **浮标自动派工**（`Ctrl+5`）：游泳 / 打捞船 / 钓鱼浮标按「选中物品数 ÷ 单人单次载重」自动算最优派遣人数；
- **收集自动派工**（`Ctrl+6`）：地标 / 建筑收集面板里按你打开的类别开关自动计算，遵守原生人数上下限与系泊点限制。

仅在人数变化时写回原生派遣数量，随存档保存；关闭即交还手动控制。

### 性能优化与探针

`F9` 性能面板：FPS（均值 + 1% 低帧）、主线程 / 渲染线程 / GPU 帧耗时、渲染统计（DrawCall / 批次 / 三角形）、逐相机耗时、脚本热点秒表、内存，每 10 秒写一行日志可整段发回分析。

内置优化（每项独立开关，禁用即回原版）：关 CTAA 空转、阴影距离钳制（100）+ 级联 2 + 阴影图 2048（阴影开销约降至原版 1/8）、SRP Batcher、关垂直同步、离屏动画冻结、装饰动画半频、粒子密度减半、日志降噪等。大城镇掉帧主要卡在 CPU 主线程，这套组合实测显著提升帧率稳定性。

## F10 模组管理器

- **模组**页：启停（禁用立即回滚补丁与订阅）、卸载（进 `Mods\.trash` 可找回）、重载（新装 mod 无需重启）；
- **按键**页：所有模组的按键统一改绑；
- **日志**页：最近 400 行，完整日志在 `BepInEx\LogOutput.log`。

> 诚实边界：Unity Mono 无法卸载已加载的程序集，「禁用」= 行为立即回滚，彻底释放内存需重启游戏。

## 从源码构建（开发者）

需要 .NET SDK；零 NuGet 依赖，全部引用指向游戏 `Flotsam_Data\Managed` 与 BepInEx `core`，目标框架 `netstandard2.1`。

```powershell
# 编译全部项目并安装进本机游戏目录（游戏需关闭）
cd ModKit
.\build.ps1 -GameDir 'F:\Game\Flotsam'

# 打包玩家整合包（dist\FlotsamModKit-<版本-日期>.zip，约 0.9MB）
.\package.ps1            # 打包当前已安装状态
.\package.ps1 -Rebuild   # 先重编译再打包
```

仓库结构：

```
ModKit/
  build.ps1 / package.ps1        构建 / 打包
  使用说明.md                     玩家向：每个模组的详细用法与全部配置项
  设计与实现方案.md                架构设计与逆向依据
  开发交接报告.md                  逆向结论速查（decompile 行号）+ 接力开发指南
  specs/                         各模组的设计文档
  src/                           源码（Abstractions 契约 / Game 游戏层 / Host 宿主 / mods 十个模组）
  tools/EnergyPlanner.Tests/     纯算法测试（dotnet run 即跑）
Mods/<id>/                       安装产物：mod.json + DLL（运行时配置首次启动自动生成）
```

新模组的最小骨架与标准接口（`IModContext` / `GamePatches` / `GameUi` 等）见 [`ModKit/使用说明.md`](ModKit/使用说明.md) §7。
