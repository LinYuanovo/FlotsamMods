### 生命周期契约（api 1.1）
`OnLoad → OnEnable → (OnTick 每帧) → OnDisable → OnUnload`，另有 `OnGameStart / OnGameEnd`（来自游戏 GameEventDispatcher）。
**mod 类不是 MonoBehaviour**：每帧逻辑要么用 `OnTick`（host 在 `ModKitRuntime.Update` 里泵），要么自建 driver GameObject（如 SailDriver、MaterialHelperDriver）。
api 1.0 → 1.1 的唯一变化：`IFlotsamMod` 增加 `OnTick()`（`FlotsamModBase` 有虚默认实现）。

## 2. 通用 UI kit（GameUi / NativeSkin / UiService）

### 2.1 NativeSkin（运行时采集原生素材）
- 进存档后从 `GameManager.UIManager.Canvas` 子树扫 `Image`/`TMP_Text`，按**精确名字表**取素材，取不到退化为子串匹配，再退化为程序化纯色。
- 当前精确名字（已验证可用）：
  - 面板体 `UI_Panel_Generic_Rounded_32x32`；描边 `UI_Panel_Generic_Border_Rounded_32x32`
  - 标题栏 `UI_Panel_Generic_Rounded_Top_32x16`（薄荷色 tint `(0.55,0.88,0.75)`）
  - 按钮 `UI_Button_Generic_Medium_Background_64x64` + pressed `..._pressed_64x64` + 描边 `UI_Button_Generic_Medium_Border_64x64`
  - 关闭 `UI_Icon_InfoPanel_Close_64x64`（off: `..._Close_off_64x64`）；拖拽把手 `UI_Icon_InfoPanel_Drag_64x64`
  - 开关图标 `UI_Icon_InfoPanel_On_64x64` / `..._Off_64x64`；定位 `UI_Icon_InfoPanel_Locate_64x64`；加减 `..._Plus/Minus_64x64`
  - 凹槽/列表底 `UI_Background_Generic_SoftSquare_84x84`、`UI_Bar_Rounded_80x80`
  - 玩家标记圆环 `UI_Bar_RadialCircle_Border_256x256`
- 颜色（取样自游戏截图）：面板纯白、描边近黑紫 `(0.14,0.12,0.19)`、文字深青黑 `(0.15,0.21,0.19)`、行背景不透明灰绿 `(0.86,0.90,0.88)/(0.93,0.96,0.95)`、危险红 `(0.87,0.30,0.26)`、成功绿 `(0.20,0.62,0.30)`。
  **行背景必须不透明**：白底上加半透明叠色会"看不见"，曾被用户报为"对比度低"。
- 字体：采集两个 TMP 字重（`Font` 正文 / `FontBold` 粗体），偏好顺序 body=`Regular/Book/Light/Medium`、bold=`Bold/SemiBold/DemiBold/Medium/Heavy`；当前游戏里正文为 `NotoSansSC-Regular SDF`。
  `GameUi.Label(..., bold:true)`（默认）优先用原生粗体字重，没有才 TMP 合成粗体。**游戏 UI 整体是粗字重，正文用 regular 会被用户认成"字体不对"**。
- 场景切换会销毁采集到的 Sprite/Font：`ModKitRuntime` 在 GameEnd 调 `UiService.ResetSkin()`→`NativeSkin.Reset()`+`GameUi.ResetFont()`；各 mod 窗口在 GameEnd 销毁、下次进存档惰性重建。
- 日志行 `[modkit] native skin: …` 含 sprite 数、font/bold 名、全部字重清单；完整名字表写 `Mods/nativeskin_names.txt`。

### 2.2 UiWindow（所有 mod 窗口的统一外壳）
- 白色九宫格面板 + 描边 + 薄荷标题栏（标题居中、左侧拖拽把手图标、右侧 **[提示开关][红色✕]** 两枚图标按钮，✕ 在最右角）。
- 拖拽标题栏移动；**双击标题栏复位位置+尺寸**；右下角 `UiResizeHandler` 握柄改尺寸。
- 位置/尺寸/提示开关全部按 `configKey` 记忆：`<key>.x/.y/.w/.h/.tips`。
  **高度存的是"含提示"的基准高度 `_canonicalH`**，显示高度 = 基准 −（提示隐藏 ? `TipsHeight` : 0）。这样恢复一个"提示已隐藏"的窗口也能正确收起。
- `TipsHeight` + `SetTips(params RectTransform[])`：隐藏提示时窗口回收高度并触发 `TipsChanged(bool)`。
  **各 mod 必须自己把"提示占的那块布局"也收起来**（否则留空白带）：
  - SailHud：Footer 容器（按钮锚 Footer 顶边），`TipsChanged` 改 Footer 高度 78↔26。
  - MaterialPanel：`TipsChanged` 移动摘要行（-30↔-2）并改滚动列表 `offsetMin.y`（52↔24）。
  - MiniMap：`TipsChanged` 改控制区高度 116↔30（窗口高度由 UiWindow 回收 86）。
- `SetClickThrough(bool)`：给 Root 加 CanvasGroup 关 raycast。**钉住原生悬浮框期间必须把材料助手面板设为 click-through**，否则面板会吞掉点向悬浮框材料格的点击（这是"点缺料没反应"的历史根因）。
- **置顶开关**：标题栏第三枚按钮（定位图标，亮=置顶/暗=沉底），按 `<key>.top` 记忆，**默认沉底**。沉底不能只改 sortingOrder：mod 画布是 Screen Space - Overlay，overlay pass 恒画在所有相机渲染（含原生 Screen Space - Camera UI 画布）之后。故沉底时镜像原生主画布（`GameManager.UIManager.Canvas`）的 renderMode/worldCamera/planeDistance/layer 并把 sortingOrder 降到 `原生order − 1000 + 本窗口order尾三位`；置顶恢复 Overlay + 原 order（`UiWindow.CaptureCanvasOrders/ApplyTopMost`，日志行 `[modkit] window '...' topOrder=... nativeCanvas=...`）。副作用：沉底窗口在打开世界地图期间不可见（原生 UICamera 被关）。HUD 按钮与 Toast 仍常驻 Overlay 顶层。
- `ContentMode`：`Uniform`（Body 按默认尺寸布局后整体等比缩放，默认）/ `None`（Body 拉伸铺满，mod 自己在 `Resized` 里重排；小地图用这个）。

### 2.3 UiService（HUD 按钮 + Toast）
- HUD 按钮：原生按钮皮肤；同锚点自动错位堆叠；`AddHudButton(id,label,onClick,anchor,config,key)` 自动可拖拽+记忆（`<key>.x/.y`）+双击复位。
- Toast：浅色面板+描边，右侧 ✕ **立即移除并让下方条目马上上移**；4s（错误 6s）自动淡出。

### 2.4 GameUi.SliderRow（原生皮肤滑块，v1.1 新增）
- `GameUi.SliderRow(parent,label,min,max,value,onChanged,onCommit,labelWidth,valueWidth,trackHeight,size,step)` 返回 `UiSliderRow`：`标签 [----o----] [数值]%' 一行，凹槽用 `SlotSprite`、填充用 Accent 纯色、手柄用 `ButtonSprite`/`DragSprite`、数值框用 `GameUi.NumberInput`（原生皮肤 `TMP_InputField`，`ContentType.IntegerNumber`）。
- **不用 UGUI `Slider`**（fill/handle 锚点难对齐），改用自建 `SliderDrag : IPointerDown/Drag/UpHandler`，直接按 `Track.rect.width` 摆 fill 宽与 handle 位；`ScreenPointToLocalPointInRectangle` 取点，故在 Uniform 缩放下也准。
- **数值可拖动、也可键入**：数值框 `onEndEdit`（回车/失焦）→ `SliderDrag.ApplyInput` 解析→钳制→吸附→`OnChanged`+`OnCommit`；拖动滑块时若数值框未聚焦则反向写回文本（`UpdateVisuals` 里 `!isFocused` 守卫，避免和玩家抢输入）。
- **档位吸附**：`SliderDrag.Step>0` 时 `SetValue` 走 `Quantize`（`Round(v/step)*step`），拖动与键入都吸附（gameplaytweaks 用 `step=5` → 5% 一档）。
- `onChanged` 拖动中实时触发（改数值），`onCommit` 松手/键入确认才触发（存盘/写日志）——避免拖一下刷屏日志、刷爆 config。
- **键入态**：数值框聚焦时经 `InputFocusRelay` 调 `GameUi.PushTyping/PopTyping`（引用计数，`UIManager.SetState(UIState.Typing)`），让快捷键与镇心移动忽略键入；面板销毁要调 `GameUi.ResetTyping()` 兜底（聚焦中被销毁不会漏 Pop）。注意 BatchManager 的 `BatchPanel` 有自己的同名私有 `PushTyping/PopTyping`，与 GameUi 的静态版互不相干。
- `SliderDrag.OnRectTransformDimensionsChange` 会在轨道首次布局/每次尺寸变化时重算填充与手柄位置：**没有它，首帧 `Track.rect.width=0`，手柄会一直贴在左端直到用户第一次拖动**（已踩坑）。
- 当前唯一使用者：`flotsam.gameplaytweaks`。

## 3. 七个 mod 的现状

### 3.1 flotsam.keyboardmove「键盘航行」v3.0.0
- 按键：`W/S/A/D` 进退转向（默认取游戏原生镇心绑定），`Return` 立即靠港，`F8` 暂停。
- 配置：`speedMultiplier`、`commitDistance`(250)、`commitRotation`(90)、`showHud`、`verbose`、`drivingEnabled`、`hud.*`、`button.*`。
- 机制（`SailDriver` + `GameMovement`）：
  - **虚拟航程**：不激活 WorldMap；每 FixedUpdate 用 `WorldMap.MovementSpeed/RotationSpeed` + `Engine.ReturnMoveableDistance` 自算位置/朝向（转向独立于前进，修过原版 early-out 导致不能原地转的坑）。
  - **单次提交**：松手或超过距离/角度阈值才 `MovementEvent.DispatchTownheartMove` 一次（= 原版关地图的那一次）。高频提交会让 `World.RepositionTownheart` 反复 despawn/respawn 全部地标 → "建筑消失"。
  - **地图移交**：航行中按 M 开地图 → 把虚拟位置 `SyncMapTownheart` 一次后停止自提交，由原版地图关闭时自己提交；`Settle` 拒绝在地图打开时运行。（修过"开/关地图后物质漂移"。）
  - 提交前 `World.UpdateTiles` 补瓦片 + 边界钳制，避免 `IsPositionInWorldBounds` 拒绝。
  - 能量：每步 `Engine.ConsumeEnergy`；冷却中 `ReturnMoveableDistance=0`。
- 「航行仪表」窗口：状态/航向/速度/本段/累计/电量可航/引擎 + 立即靠港/暂停按钮 + 可隐藏提示；被阻挡时直接显示原因（含 `GameApi.MovementBlockerCount` 排除地图自身 blocker 的逻辑——**关过一次地图后 `IsTownMovementBlocked` 永久为真**，这是"键盘移动失效"的历史根因）。
- 已知历史根因备查：`WorldMap.Deactivate` 结尾 `AddMovementBlocker(this)`（decompile 159742）。
- **移动保护（对齐世界地图碰撞）**：`GameMovement.BlocksMovement(from,to,voyageBase,out why)` —— 点在多边形内测试两组来源：`Buildable.BlockingPolygons`（玩家建筑/系泊阻挡，与建造重叠检测同一集合）+ 各地标 spawner 的 `TileSpacePolygon`（岛轮廓；测试点按 `WorldPosition2D - TilePosition` 反偏移；**岛没有 Obstacle 组件，`Obstacle.AllObstacles` 和 `WorldMap.Obstacles` 都指望不上**）。拒绝"从多边形外跨进内"的步：手动航行 Blocked「离建筑/地标太近」，自动航行取消+提示；起点或当前点已在多边形内的豁免（镇心自身平台/已卡住时能开出）。

### 3.2 flotsam.minimap「常驻小地图」v3.1.0
- 按键：`M` 开关，`Home` 回镇心并跟随。
- 配置：`visible`、`followTownheart`、`viewRange`(1400)、`refreshHz`(10)、`showFog/fogInvert/showIcons/showTown`、`iconSize`(20)、`iconMinAlpha`、`window.*`、`button.*`、`schema`。
- 视图：`MiniMapView`，**非方形贴图铺满窗口可用区**（缩放比例取短边；改窗口尺寸会重建贴图，真正改变视野而不是放大马赛克）。
- 图层：海面= `WorldTile.WorldBounds` 矩形（teal `(56,138,156)`）+ 边线；迷雾= `WorldTile.FogOfWarAlphas` 真实战争迷雾（深一档 `(14,32,44)`）；游泳圈白环；
  我的建筑= 贴图内 7px 描边/5px 亮芯小点（**不要用投影方块或建筑图标：图标多为 null、投影会糊成黑块**）；
  地标/兴趣点/漂浮物= 原生 `ISpawner.Icon` 的 UGUI Image 池；
  玩家= 白圈 + **128px 逐像素抗锯齿箭头**（尺寸 = `clamp(iconSize*0.75,12,22)*1.5`）+ 深色外描边，航行中变绿。
- 刷新：贴图按 `refreshHz` 重绘；玩家标记每帧更新（跟随键盘航行的未提交位置 `GameMovement.DisplayPosition`）。
- 交互：滚轮缩放（以光标为中心）、左键拖拽平移（取消跟随）、**左键单击=自动航行到该点**（`GameMovement.AutoActive/AutoTarget/AutoInput` 自动驾驶层，SailDriver 消费：转向→对准推进→60u 内刹车、18u 内靠港提交；方向键接管、右键/双击/开地图/被阻挡取消；目标点画薄荷十字环）、双击居中（取消自动航行）、右键回镇心并取消自动航行。
- **采完的资源不再显示**：三通道过滤（`GameWorld.IsDisposed/IsDepleted`）——POI 用世界地图自己的判据 `PointOfInterestSpawner.ReturnSpawnerCount()<=0`（`WorldMapFlotsam.OnSalvage` 就是据此销毁标记的；反射成分清点保留为后备）；地标监听 `GameEventType.LandmarkDisposed`（spawner 本身仍留在 tile 列表里）。换存档自动清空 disposed 集合。
- 历史根因备查：旧版 `OnGameStart` 调 `FitWorld()` 把跟随关掉并缩到全世界且写进 config → "小地图不刷新"；已有 `schema=2` 迁移自动修复。

### 3.3 flotsam.materialhelper「材料助手」v4.3.0
- 按键：`G`（按住+点击=补齐；单按=只打开面板）、`H` 开关面板。
- 配置：`zoomLevel`、`chainDepth`(2)、`showPanel`、`pinTooltips`、`hookNativeCells`、`verbose`、`panel.*`、`button.*`。
- Harmony 补丁（`OnEnable` 注册，日志会打印每条）：
  | 目标 | 类型 | 作用 |
  |---|---|---|
  | `RecipeDisplay.UpdateDisplay` | postfix | 给工坊配方材料格挂 `IngredientRowHook`（左键补齐/右键定位） |
  | `ProductionPanelRecipeToggle.Initialize / UpdateState` | postfix | 挂/刷新配方行「缺 N」徽标（仅展示） |
  | `BuildableTooltipItemSlot.Initialize(CountedItemProperty,bool)` | postfix | 挂 `ConstructionSlotHook`（建造悬浮框材料格可点） |
  | `BuildableTooltip.HideTooltip` | **prefix** | 钉住期间禁止建造悬浮框自隐藏（它直接 `SetActive(false)`，绕过 TooltipPanel） |
  | `TooltipPanel.Update` / `HideTooltip_Internal` | prefix | 钉住期间禁止物品悬浮框跟随/隐藏 |
- **交互映射（当前设计，用户确认过的目标行为）**：
  1. 点击要造的建筑（建造栏条目）→ 钉住建造悬浮框 + 材料助手显示该蓝图需求（`CaptureBlueprint`，含 1.2s 重试等格子生成）；
  2. 钉住后点击缺的材料 → **只定位**（飞向并打开生产它的建筑面板）；不能生产的弹「如何获得」（扫描 `LandmarkInteractableWithComposition.Composition` 给打捞来源）；
  3. 按住 G 点要造的建筑 → **直接补齐整条链**（`AimDetect`：逐项 `ScheduleBatches` + 递归 `FillChain`）；
  4. 点悬浮框以外 → 解除钉住；离开正常游戏状态（菜单/地图/对话）自动解除；
  5. 钉住期间材料助手面板 click-through，避免吞点击。
- 面板：跟随打开的建筑面板（工坊=选中配方材料；建造中=建造材料）或手动蓝图模式；每行 图标/名称/库存·需求·在途/补齐/定位；「一键补齐」= 手动模式逐行补齐，否则补当前配方整链。
- 排产 API：`GameProduction.ScheduleBatches / FillChain / FindProducersFor / CandidateSnapshot / IncomingCounts / SalvageSources`（后两个是"一次遍历"快照，避免每行扫全部生产者）。

### 平衡系统（gameplaytweaks 逆向）
- **重量不影响最高速度**：`WorldMap.MovementSpeed => EnergyDevTools.ApplyMovementSpeed(_movementSpeed) * _engine.ReturnMovementSpeed()`（159656），`_movementSpeed` 是定值(50)，`Engine.ReturnMovementSpeed()=Buildable.ReturnModifier(ModifierType.MovementSpeed)`（22359）只吃**模块**修正，与重量无关。重量的真实代价是**每单位距离能耗**：`Engine.ReturnEelsPerUnit()=GameplaySettings.ReturnEelsPerUnit(TownWeight)*ReturnModifier(MovementEnergyCost)`（22405）→ `ComputeEelsPerUnit(weight)`（143089，Function 模式 `offset + w*scalar + base^(max(0,w-1))`，w=weight/1000；Tiers 模式按阈值查表）。能量耗尽→`IsCoolingDown`→`ReturnMoveableDistance=0`，所以"重→费电→频繁冷却→更慢"是间接的。
- **载重上限（能否再建）**：`PlaceableProperties.ReturnCanBePlaced`（18065）里 `flag3 = IgnoreWeightForPlacement || Engine.CanTug(this)`；`Engine.CanTug = 建筑重量 <= TownAvailableTugCapacity`（22441）；`TownAvailableTugCapacity=max(_townTugCapacity-TownWeight,0)`、`_townTugCapacity=ReturnTownTugCapacity()`（= 所有启用引擎 `_tugCapacity` 之和）在 `Engine.LateUpdate`（22255-22257）每帧算。**没有"分档硬禁建"**，玩家感知的"八级建不了"其实是 weight 触顶 capacity → available=0。`TownUsedTugCapacityPercentage` 驱动 `Engine.WeightTier`（ScriptableObject，22565，只含 EelsPerUnit/Color，供载重条 58301 与配色）。
- **发电**：`EnergyGrid.ReturnEnergyProduction()=Σ producer.Production`（39070），`CalculateEfficiency()`（38834）每帧 `production*dt` 入网。三类 `IEnergyGridProducer`：`EnergyPassiveGenerator.Production=EnergyRate`（风/水，21711）、`EnergyItemProducer.Production=PowerRate`（燃料，21098）、`EnergyManualProducer.Production=ReturnAgentEnergyGeneration()`（人力，21431）。改 `Production` getter 即改实际入网电量（且 `ReturnEnergyProductionExcludingProducer`/优先级判断同源，保持一致）。
- **美观度**：`Community.BeautyScore`（7344）= Σ `construction.Buildable.ReturnBeautyScore()`（`UpdateBeautyScore` 7783，缓存 int，变化时发 `BeautyScoreUpdated`）；`Buildable.ReturnBeautyScore()=Properties.BeautyScore + DecorationSlots.BeautyScore`（17387）。**影响士气**：`TownBeautyMoraleEffect`（命名空间 `PajamaLlama.Flotsam.Morale`）在 `UpdateModifier`（217339）按 `_modifierThresholds`（`Threshold<=BeautyScore` 取该档 `Modifier`）算出 `_modifier`，`ReturnModifier()`（217301）被 `Morale.ReturnMoraleModifierSum`（217798）累加。改建筑分要 `UpdateBeautyScore()` 重算缓存；改士气读取处 `ReturnModifier()` 即时生效。

## 5. 接力开发指南

1. 先读：本文件 → `ModKit/设计与实现方案.md` → 目标 mod 源码 → 需要时查 `_mod_recon` 行号。
2. 改代码 → `ModKit\build.ps1` → **重启游戏**验证 → 读 `BepInEx\LogOutput.log`。
3. 排错顺序：日志里该 mod 的行为日志（pin/resolve/aim-fill/capture/settled）→ 补丁注册行 → 再怀疑逻辑。
4. UI 改动遵守第 2 节约定（原生皮肤、窗口外壳、提示回收、位置记忆），不要新造一套样式。
5. **不要用 PowerShell `Set-Content` 打补丁改 .cs**（曾整文件覆盖事故）；用编辑工具做精确替换。
6. 新增每帧逻辑：mod 类里用 `OnTick`，或建 driver GameObject；不要在 mod 类写 `Update()`（不会执行）。
7. 配置新增键记得：默认值 + 必要时 `schema` 迁移（旧 config 会残留）。
8. 性能红线：小地图/材料面板都是高频刷新；遍历生产者/瓦片要用快照 API；`FindObjectsOfType` 只允许低频或一次性调用。
